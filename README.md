## Unity 第三次作業－占卜輪盤

### 一、製作流程
1. 建立 Unity 2D 專案，匯入輪盤及指針素材。
2. 建立 C# 腳本，使用 `transform.Rotate()` 控制輪盤旋轉。
3. 利用 `rotSpeed *= 0.96f` 讓輪盤逐漸減速並停止。
4. 使用 `Random.Range()` 讓每次旋轉的結果不同。
5. 加入 `isSpinning` 判斷，避免旋轉時重複點擊。
6. 使用 Audio Source 加入旋轉音效及停止提示音。
7. 測試遊戲功能，並將專案上傳至 GitHub。

### 二、遊戲操作
點擊滑鼠左鍵後，輪盤開始隨機旋轉並播放音效。旋轉期間無法重複點擊，輪盤會逐漸減速，完全停止後播放「叮」的提示音，並可再次點擊進行下一輪占卜。
